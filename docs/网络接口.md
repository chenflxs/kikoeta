# 网络接口

## 歌词库广播（v1）

在设备 A 的“设置 → 歌词与桌面歌词”中开启“歌词库广播”后，应用在 IPv4 的 **2377** 端口提供只读 HTTP 接口。设备 B 可在歌词库的“导入 → 远程库”中输入 A 的地址，例如 `http://192.168.1.20:2377`。

下表中的路径均相对于该地址。接口只接受 `GET`，返回 JSON；广播端只列出本地库中有歌词文件的作品，不转发从其他设备同步的在线作品。当前内置服务使用 HTTP，客户端也接受由外部服务提供的 HTTPS 地址。

| 接口 | 用途 |
|---|---|
| `GET /api/lyrics-library/v1/works` | 获取作品索引 |
| `GET /api/lyrics-library/v1/works/{workId}/files` | 获取一部作品的歌词文件索引，不含文件内容 |
| `GET /api/lyrics-library/v1/works/{workId}/lyrics` | 获取一部作品当前可读取的全部歌词文件内容 |

`workId` 为作品号，接受 `RJ`、`VJ` 或 `BJ` 后接数字；接口会将其转为大写。以下示例中的地址与作品号仅作示意。

### 作品索引

请求：`GET http://192.168.1.20:2377/api/lyrics-library/v1/works`

```json
{
  "version": 1,
  "works": [
    { "workId": "RJ123", "isAi": true, "fileCount": 2 }
  ]
}
```

`version` 是接口版本。`works` 按作品号排序；`isAi` 表示该作品的本地索引中至少有一条 AI 歌词记录，`fileCount` 是歌词/字幕文件数量。没有可用歌词文件的作品不会出现在列表中。

### 文件索引

请求：`GET http://192.168.1.20:2377/api/lyrics-library/v1/works/RJ123/files`

```json
{
  "workId": "RJ123",
  "files": [
    {
      "relativePath": "disc1/track01.lrc",
      "name": "track01.lrc",
      "extension": ".lrc",
      "isAi": true
    }
  ]
}
```

`relativePath` 是相对于作品索引目录的文件路径，使用 `/` 分隔。`extension` 包含前导点；`isAi` 是该文件所属歌词目录的 AI 标记。此接口只提供元数据，适合在线库浏览。

### 下载作品歌词

请求：`GET http://192.168.1.20:2377/api/lyrics-library/v1/works/RJ123/lyrics`

```json
{
  "workId": "RJ123",
  "files": [
    {
      "relativePath": "disc1/track01.lrc",
      "name": "track01.lrc",
      "extension": ".lrc",
      "isAi": true,
      "content": "SGVsbG8K"
    }
  ]
}
```

`content` 是文件**原始字节**的 Base64 编码，不是按某种固定字符集转换后的文本。服务端逐个读取该作品的歌词文件；读取失败的文件会从响应中略过。客户端会检查相对路径与支持的歌词扩展名（`.lrc`、`.txt`、`.srt`、`.vtt`、`.ass`、`.ssa`），再把可用文件写入本地歌词库。

### 同步与标记

1. B 可导入多个远程库。每次导入只请求该地址的作品索引，并保存作品元数据；尚不下载歌词。`online` 不属于接口响应字段，而是 B 同步时写入本地记录的标记；它与独立的 `isAi` 标记可以同时为 `true`。
2. 如果 B 的本地歌词库已有同一作品号，跳过该作品的远程索引，不给本地记录添加 `online` 标记。不同远程库的同一作品可以同时留在在线索引中。
3. 导入弹窗中的远程库列表可拖动排序，越靠上优先级越高。B 浏览在线作品文件时调用最高优先级可用来源的 `/files`；播放并匹配歌词时，如果本地没有该作品的歌词文件，则优先向该来源请求 `/lyrics`，失败后尝试较低优先级来源。成功导入本地后移除该作品的 `online` 标记，保留文件的 AI 标记。

### 索引刷新

- 进入“在线”页或在“本地 / 在线”之间切换时，不会自动请求远程作品索引。
- 导入远程库时只拉取当次输入的地址；导入弹窗中每个已导入地址旁的刷新按钮只拉取该库。
- 歌词库右上角的刷新按钮在“在线”页会依照列表顺序逐个拉取所有已导入的远程库；没有已导入库时直接显示空列表。
- 客户端同一时间只进行一个作品索引请求，合并同时发往同一地址的请求；同一地址两次请求的起始时间至少相隔 2 秒，不同地址的请求至少相隔 300 毫秒。手动刷新仍会拉取索引，但不会连续密集请求广播设备。

### 错误与访问范围

| HTTP 状态 | 响应示例 | 含义 |
|---|---|---|
| `405` | `{"error":"read_only"}` | 使用了 `GET` 以外的方法 |
| `404` | `{"error":"not_found"}` | 路径或操作不存在 |
| `404` | `{"error":"work_not_found"}` | 作品号无效，或本地库没有该作品 |
| `500` | `{"error":"request_failed"}` | 服务端处理请求失败 |

响应使用 JSON，带 `Cache-Control: no-store`。当前广播接口没有身份验证，监听所有 IPv4 地址；请在可信网络中开启，并通过系统防火墙控制可访问的设备。内置服务不提供 TLS，需要 HTTPS 时可在前面配置反向代理。

实现位置：`app/lib/services/lyrics_library_broadcast_service.dart`、`app/lib/services/lyrics_library_remote_client.dart`、`app/lib/services/lyrics_library_service.dart`。
