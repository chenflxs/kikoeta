# 八项优化：普通用户找茬回归

日期：2026-10-09。

范围限定在普通用户能执行的操作：点击、滚动、筛选、切换曲目/来源、导入文件、暂停/恢复/退出、断网重试，以及通过文件管理器删除或改动下载文件。所有文件和设置均使用临时夹具；未操作现有下载、真实歌词库或系统代理。

## 场景覆盖

| 优化项 | 找茬方式 | 验证方式 |
| --- | --- | --- |
| 断点续传完整性 | 中途断线与重启；服务端忽略续传、更新文件或返回错误范围；删除/截短已经下载的文件后重试 | 本地 HTTP、真实临时文件、比对最终字节及下载状态 |
| 下载暂停即时生效 | 服务器不发响应头/发部分内容后停住；快速暂停再恢复；暂停全部；删除正在下载的作品 | 服务端保持停滞，先确认客户端取消或后续任务完成，再释放服务端 |
| 减少主线程磁盘操作 | 进度刷新与缓存查询；恢复时一次异步校准；校准期间暂停、删除和关闭 | 原有持久化/缓存回归与新增下载控制测试；未测真机帧耗时 |
| 统一歌词加载入口 | A→B→A 快速切曲；旧响应后到；关闭自动匹配；格式失败后回退；翻译保存/手动重选 | 隔离 LyricsHub 状态及真实临时歌词文件，文字解码使用 Rust mock |
| 大歌词库查询 | 搜索/清空/切来源；首批之外的作品；计数失败与重试；快速点两个作品；离页后响应返回 | Flutter 页面点击测试、可控异步响应、原有大索引/缓存回归 |
| 歌词导入 | 作品号出现在文件名；规范化目录及超长文件名冲突；部分导入失败后重试；多远程源失败回退与并发懒下载 | 临时目录/ZIP、本地 HTTP、核对导入结果和原文件内容 |
| 深层目录与长文件树 | 1200 层目录；万文件首屏及普通滚动；350 行滚到末尾再返回；重复过滤、刷新加文件、跨目录/作品同名、多选与折叠 | 算法与实际页面 widget 回归；360px 宽、200% 字体下滚动及点击 |
| 网络连接 | 断连后重试、超时后重试、取消慢请求、错误代理修正与 A/B/A/关闭、HTTP 503 后重试、并发请求 | 真实本地 TCP/HTTP；顺序请求检查连接复用，并发请求检查响应与逐请求鉴权 |

## 已复现并修复的问题

- 服务器停住时，已收到响应的下载无法被暂停；快速恢复、退出和删除也会被拖住。现在取消会关闭当前传输的客户端，先释放分片句柄再删除目录。
- 下载完成缓存过期时，丢失或截短的文件会被跳过，甚至被宣称全部完成。恢复入口会异步校准，运行中的队列在挑选下一个文件前等待校准；已完成记录重启后发现缺文件，保留暂停状态，等用户开始后补下。
- 目录导入把 `RJ100001.lrc` 当作作品目录名称，导致扩展名丢失；冲突预检和实际复制使用不同名称规则，漏报冲突。现在文件保留标题及扩展名，预检和复制共用映射规则。
- 歌词库计数和文件列表的 I/O 异常未被处理；切换来源后迟到的旧列表仍会弹出。现在失败会显示可重试状态，旧视图/旧点击的请求不能覆盖当前操作。
- 下载文件与作品多选在记录移除后残留选择，错误显示“取消全选”。现在移除无效选择，同时保留仍然存在的选中项。
- 窄屏大字体时，作品元数据、下载进度条和固定高度卡片溢出。现在元数据换行，进度条和卡片随内容增高，保留系统字体大小。
- 作品卡片重排时，歌词徽标的 `setState` 回调返回 Future，引发 Flutter 异常。现在使用同步赋值回调。

## 验证结果

Flutter 全量回归 **192/192 通过**，Dart 完整静态检查无问题，`git diff --check` 通过。Rust 共 **37 项通过、1 项既有联网翻译测试跳过**（该测试需要访问 Google）。

## 证据边界

这次使用本地服务、临时文件和 Flutter 无窗口 widget 测试；没有真机触控、真实音频播放、发布包或公网延迟/速度证据。变量行高的列表直接跳到远端仍可能需要测量中间行，万文件测试验证的是首屏及普通滚动。

并发 TCP 测试的服务端主动关闭连接，只用于响应与鉴权隔离；连接复用由独立的顺序请求及错误后重试测试验证。

新增 Dart 回归保存在 `app/test/`，该目录仍受仓库现有忽略规则影响。本次未修改忽略规则或暂存文件。
