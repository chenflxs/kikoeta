# Kikoeta 文件功能索引

> 面向 ASMR 音声的 Windows / Android 本地收听客户端（Flutter + Rust）。本文件用于快速定位源码文件与对应功能，随代码变更同步更新。

最后更新：2026-11-08

## 维护说明

- 新增 / 删除源码文件后，请同步更新对应目录表格与「功能 → 文件速查」。
- `test/`、`tests/`、`checks/` 和测试夹具仅供本地验证，由 `.gitignore` 排除，不纳入版本控制或本索引。
- `src/rust/` 与 `src/frb_generated.rs` 为 flutter_rust_bridge 自动生成，一般不在索引中展开具体函数。
- 生成代码（`frb_generated*.dart`、`frb_generated.rs`）由 `flutter_rust_bridge_codegen` 重新生成，改动会被覆盖。
