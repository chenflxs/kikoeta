# Kikoeta 文件功能索引

> 面向 ASMR 音声的 Windows / Android 本地收听客户端（Flutter + Rust）。本文件用于快速定位源码文件与对应功能，随代码变更同步更新。

最后更新：2026-08-28

## 目录总览

```
kikoeta/
├── README.md                项目说明、功能清单、构建方法
├── LICENSE                  许可（MIT）
├── docs/                    文档目录（本索引与 README 截图）
│   ├── image/               应用界面截图
│   └── 文件功能索引.md       文件定位速查
└── app/                     Flutter 应用主体

    │   ├── pages/           各界面页面
    │   ├── services/        服务层（播放、歌词、设置、更新检测、API 等）
    │   └── src/rust/        flutter_rust_bridge 生成的 Dart 绑定
    ├── rust/                 Rust 核心（API 请求、翻译、文本处理、代理、存储）
```

## app/lib/（Dart 源码）

### 入口与全局

| 文件 | 功能 |
|---|---|
| `main.dart` | 应用入口 `main()`：初始化 Rust/SettingsStore、更新检测、Windows 快捷方式与托盘、MediaKit、Android 音频与 Media3 桥接、SleepTimer、剪贴板检测、通知权限、桌面/安卓歌词悬浮窗、LyricsHub；`KikoetaApp`（MaterialApp、主题、路由）与 `Shell`（窄屏底部导航 / 宽屏侧边导航、迷你播放器叠层） |
| `routes.dart` | 作品详情页路由：缩放 + 淡入的展开过渡动画（`buildWorkRoute`） |

| `data.dart` | 数据模型与全局状态：`Work`（作品）、`MediaNode`（媒体树节点）、`LyricLine`、`CustomSite`（自建站点）、`PlaylistEntry`/`PlaylistInfo`（歌单）；`AppState extends ChangeNotifier` 聚合全部运行时状态（筛选、搜索、收藏、播放、历史、歌单、黑名单、翻译缓存、设置项）并负责持久化，含 asmr.one 推荐页的本地 UUID |
| `widgets.dart` | 通用组件：`CoverArt`（封面 + 渐变底）、`Pulse`（播放脉冲动画）、`SkeletonBox`（加载骨架）、`RustImageProvider`（经 Rust 取字节的自定义 ImageProvider）、`AgeBadge`（年龄分级角标）、`WorkCard`（作品卡片）、`Pill`、`ResponsiveGrid`（自适应网格）、`MenuItem`/`MenuPanel`（菜单）、`HomeSearchBar`、`MiniPlayer`（迷你播放器） |
| `sheets.dart` | 底部弹层集合：`showServerSheet`（服务器选择）、`showSiteSheet`（自建站点编辑）、`showOneConfigSheet`（one 站账号配置）、`showEqSheet`（10 段均衡器）、`showSleepSheet`（定时关闭设置） |

|---|---|

| `player_page.dart` | 播放器页：播放控制与进度、播放模式、音量与两级响度提升（上限 120 / 200）、均衡器、歌词面板（在线/离线、偏移、简繁转换状态持久化、自动跟随；手动切歌与自动续播均重新匹配）、定时关闭、迷你歌词窗 |
| `login_page.dart` | 登录页：asmr.one 账号登录、网络代理配置，以及自建服务器的新增、选择与启用 |

| `history_page.dart` | 历史页：搜索历史与播放历史列表、清空操作 |
| `playlists_page.dart` | 歌单页：创建/重命名/删除歌单，`PlaylistDetailPage` 歌单详情与音频文件管理 |
| `blacklist_page.dart` | 黑名单页：按标签/社团/声优/作品维护黑名单 |
| `more_page.dart` | 更多页：随心听、服务器状态、历史/歌单/黑名单/设置等入口 |
| `settings_page.dart` | 设置页：服务器与账号、翻译引擎（OpenAI 兼容模型检测、选择与手动输入）、代理、更新检测、歌词悬浮窗外观、均衡器、播放与音频类型偏好、电池优化、完全重置 |

### services/（服务层）

| 文件 | 功能 |
|---|---|
| `api_service.dart` | API 客户端：`ApiService` 组装请求并解析响应（作品列表、asmr.one 热门/推荐使用 Rust 网络层的 recommender POST 接口、随心听使用独立的 `betterRandom` 单作品请求、搜索/详情/曲目/歌单/登录/歌词检测/评价），区分 asmr.one 与 kikoeru-express 参数差异并传递登录令牌；`WorksPage` 分页结果；`LyricCandidate` 歌词候选 |
| `player_service.dart` | `AppPlayer` 全局播放器单例：封装 media_kit `Player`，处理媒体缓存、本地流媒体代理与播放错误，暴露 position/duration/playing/buffering/completed/error 流；播放器随应用常驻，退出页面不销毁 |
| `settings_store.dart` | `SettingsStore`：Rust 侧 SQLite 设置存储的 Dart 桥接（init/get/set/clearAll） |
| `app_paths.dart` | `AppPaths`：解析应用数据目录；Windows 优先使用可执行文件旁的 `kikoeta_data/`，不可写时回退系统目录 |
| `shortcut_service.dart` | `ShortcutService`：Windows Release 首次运行时创建桌面和开始菜单快捷方式 |
| `update_service.dart` | 更新服务检测：优先项目更新服务，异常时回退 GitHub Releases；读取编译时包版本，支持启动后自动检查、手动检查、版本比较与更新提示 |
| `lyrics_hub.dart` | `LyricsHub` 歌词全局中枢：持有当前歌词列表、全局监听播放位置、简繁转换缓存，播放器页关闭后仍刷新悬浮窗 |
| `sleep_timer.dart` | `SleepTimer` 定时关闭：到点停止播放，桌面端退出进程（幂等触发） |
| `clipboard_watcher.dart` | `ClipboardWatcher` 剪贴板 RJ 号检测（3 秒轮询，检测到新 RJ 提示一键搜索） |
| `desktop_lyrics_overlay.dart` | `DesktopLyricsOverlay` Windows 桌面歌词悬浮窗（win32/ffi 无边框置顶窗口，支持锁定、字号与颜色；高分辨率灰阶遮罩下采样，减少文字锯齿） |
| `windows_tray_service.dart` | `WindowsTrayService`：拦截 Windows 关闭事件并按设置隐藏至系统托盘；右键菜单依次提供显示首页、桌面歌词开关、暂停/播放切换和退出（解除关闭拦截后走原生窗口清理流程） |
| `android_audio.dart` | `AndroidAudio`：安卓耳机拔出自动暂停、音频焦点控制（MethodChannel `kikoeta/audio_control`） |
| `android_battery.dart` | `AndroidBattery`：电池优化白名单查询/请求（后台播放不被省电策略中断） |
| `android_lyrics_overlay.dart` | `AndroidLyricsOverlay`：安卓悬浮歌词窗控制（显示/隐藏、锁定状态回调） |
| `android_media3.dart` | `AndroidMedia3`：Jetpack Media3 媒体会话桥接（播放状态上报原生、原生命令回传 Dart） |
| `android_notification.dart` | `AndroidNotification`：Android 13+ 通知权限查询与请求 |

## app/rust/（Rust 核心）

| 文件 | 功能 |
|---|---|
| `Cargo.toml` | Rust crate 依赖（reqwest、tiny_http、encoding_rs、rusqlite 等） |
| `src/lib.rs` | crate 入口，声明 `api` 模块 |
| `src/api/mod.rs` | api 模块汇总 |
| `src/api/simple.rs` | 设置与数据存储：SQLite 键值设置（`get_setting`/`set_setting`/`clear_all_settings`）、按站点保存 token、打开设置目录、HTTP 代理配置读取 |
| `src/api/kikoeru_api.rs` | 服务端 HTTP API：作品列表/搜索（含年龄、字幕、排序、随机种子参数）、随心听专用单作品随机请求（`GET /api/works?order=betterRandom`）、asmr.one 热门与推荐（`/api/recommender/popular`、`/api/recommender/recommend-for-user`）、详情、曲目树、二进制字节下载、健康检查、登录、LRC 检测、歌单增删查、我的评价；统一使用 Rust `reqwest` 网络层并按站点附带 Bearer 令牌 |
| `src/api/proxy.rs` | 本地流媒体代理：tiny_http 起本地端口，代理音视频 URL（解决跨域/防盗链），Dart 侧通过 `proxy_port`/`api_stream_proxy_url` 获取代理地址 |
| `src/api/textcodec.rs` | 文本解码：`api_decode_text` 自动识别编码（UTF-8 / Shift-JIS / GBK / UTF-16 / ISO-2022-JP 等），`DecodedText` 结果类型 |
| `src/api/textconv.rs` | 简繁转换：`api_convert_text`（S→T / T→S，字符表 + 词汇表 + 方向自动检测，带缓存） |
| `src/api/translate.rs` | 翻译引擎：OpenAI 兼容接口（Qwen/DeepSeek 分别禁用思考模式、序号行协议防止译文错位、兼容推理模型返回）/ Google / DeepL / Microsoft / 连通性测试（`api_translate_*`） |
| `src/frb_generated.rs` | FRB 自动生成的桥接代码，**勿手改** |
| `examples/proxy_check.rs` | 代理功能命令行验证示例 |

## app/android/（Android 原生）

| 文件 | 功能 |
|---|---|
| `MainActivity.kt` | FlutterActivity 入口；注册各 MethodChannel（音频控制、电池、通知、歌词悬浮窗、Media3），注入 Media3 命令回调 |
| `BridgePlayer.kt` | Media3 `SimpleBasePlayer` 桥接门面：真实播放由 Dart 侧 mpv 执行，本类仅向 MediaSession 提供状态快照并把命令转发给 Dart |
| `KikoetaMediaSessionService.kt` | Media3 前台服务：锁屏媒体卡片与通知栏控制（手动构建通知 + startForeground），`Media3Bridge` 单例 |
| `LyricsOverlay.kt` | 安卓歌词悬浮窗（WindowManager 覆盖层）：可拖动、锁定后点击穿透、横/竖屏锁定状态分开记忆，`LockIconView` 锁定按钮 |
| `AndroidManifest.xml` | 权限声明：通知、悬浮窗、电池优化、前台服务等 |

## 维护说明

- 新增 / 删除源码文件后，请同步更新对应目录表格与「功能 → 文件速查」。
- `src/rust/` 与 `src/frb_generated.rs` 为 flutter_rust_bridge 自动生成，一般不在索引中展开具体函数。
- 生成代码（`frb_generated*.dart`、`frb_generated.rs`）由 `flutter_rust_bridge_codegen` 重新生成，改动会被覆盖。
